# Music Studio — Тон

Laravel + Livewire: каталог студий, поиск, фильтр по пианино, регистрация,
диапазон цены, бронирование по целым часам и личный кабинет.

## Локальный запуск

Для зависимостей из `composer.lock` нужны PHP 8.4.1+, Composer и Node.js, совместимый с Vite Plus
(20.19+, 22.18+ или 24.11+). PHP должен поддерживать SQLite.

```sh
composer install
```

Скопируйте `.env.example` в `.env` и создайте пустой файл
`database/database.sqlite`. По умолчанию используется SQLite.

```sh
php artisan key:generate
php artisan migrate
php artisan db:seed --class=StudioSeeder
php artisan serve --host=127.0.0.1 --port=8000
```

Откройте http://127.0.0.1:8000. Зарегистрируйтесь через интерфейс:
демонстрационный сидер создаёт только три студии, без учётных записей.
Повторный запуск сидера не создаёт дубликаты и не перезаписывает студии.
Названия, описания и цены в нём — демонстрационные данные.

Основной интерфейс использует `public/css/studio.css` и Livewire,
поэтому отдельный Node-сервер для него не требуется. Для Vite-ресурсов:

```sh
npm ci
npm run dev
# либо production-сборка
npm run build
```

Время бронирования задаётся в `config/app.php` (`app.timezone`).
Рабочий интервал — 10:00–22:00, в пределах одного дня.
Доступность и итоговую стоимость сервер проверяет при подтверждении.

## Проверки

```sh
php artisan test
composer lint:check
composer types:check
```

API доступен под `/api`: студии, регистрация, вход и создание брони
с токеном Sanctum. Веб-интерфейс использует сессионную авторизацию.

Чтение каталога публичное. Создание, изменение и удаление студий через API
требует токен пользователя с `role = admin`. Роль назначается на стороне
сервера, через регистрацию её получить нельзя. Вход и регистрация API
ограничены 10 запросами в минуту с одного IP.
Студии с историей бронирований нельзя удалять (API отвечает `409`):
их можно отключить через `is_active = false`, сохранив историю клиентов.

При входе из формы бронирования выбранные дата и часы сохраняются в сессии
и восстанавливаются после авторизации. Стоимость рассчитывается в копейках
одинаково для предварительного итога и подтверждённой брони.

Анимации интерфейса используют CSS, включая вращение пластинки и появление
карточек при прокрутке в поддерживающих это браузерах. Системная настройка
уменьшения движения отключает анимации.

## Клиентский интерфейс

Фильтры каталога и страница результатов сохраняются в URL. Поиск, наличие
пианино и диапазон цены можно сбросить одной кнопкой. Доступна сортировка
по названию и цене в обе стороны.

В форме бронирования есть семь ближайших дат, выбор длительности и сетка
часов. `AvailabilityService` показывает свободные, занятые и прошедшие часы
без данных других клиентов. Выбранная длительность должна целиком помещаться
в свободный интервал. Расписание обновляется каждые 30 секунд; `BookingService`
повторно проверяет доступность и стоимость в транзакции при подтверждении.
При конфликте форма сохраняет выбор и показывает актуальное расписание.

На телефоне панель с итогом ведёт к форме и скрывается, когда форма видна,
чтобы не перекрывать поля. При входе показано резюме сохранённого выбора;
пароль можно показать или скрыть. Кабинет разделён на предстоящие репетиции
и историю, ближайшая репетиция выделена отдельно. «Забронировать снова»
открывает новую форму активной студии и не создаёт бронь автоматически.

Основной JS для уведомления об ошибке соединения — `public/js/studio.js`.
После сбоя отправки брони сначала проверьте кабинет: сервер мог обработать
запрос, даже если ответ не дошёл. Повторная отправка не выполняется автоматически.
